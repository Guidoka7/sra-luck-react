# Áreas administrativas preservadas

- `/admin/configuracoes`: central de controle completa.
- `/admin/configuracoes/monitoramento`: diagnóstico e observabilidade.
- `/admin/notificacoes`: automação, templates, envio manual e logs.
- Alternador claro/escuro permanece disponível no painel.
- Paleta administrativa pode ser personalizada em Configurações.

As demais áreas continuam usando o painel profissional de crédito já implementado.
