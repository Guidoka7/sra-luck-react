# Refino administrativo sem regressão

Este ajuste restaura recursos que existiam antes da reformulação visual e mantém os novos módulos de crédito.

- Configurações completas: identidade, orçamento, PIX, QR Code, desconto, contatos e bloqueio global da agenda.
- Aparência: modo claro/escuro persistente e paleta editável, com padrão Sra. Luck.
- Notificações: visão geral, automação, templates, envio manual e logs.
- Monitoramento: diagnóstico, falhas, dispositivos/PWA e saúde operacional.
- Preview Vercel: `/api/*` é roteado para a Function antes do fallback SPA.

Nenhum desses módulos deve ser reduzido para uma versão meramente demonstrativa durante novos refinamentos visuais.
